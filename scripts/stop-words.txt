# Публичная часть словаря стоп-слов: только структурные шаблоны, ни одного литерального имени.
# Одна POSIX ERE на строку; `#` — комментарий. Границы слова — только явными классами
# (^|[^A-Za-z0-9_]) … ([^A-Za-z0-9_]|$): без \b, \<, \> и -w — сторож обязан давать один вердикт
# на GNU grep в CI и на BSD grep рабочей машины. Литеральные имена — в приватной части
# (секрет STOP_WORDS_PRIVATE или файл STOP_WORDS_PRIVATE_FILE). Законные токены,
# совпадающие с шаблонами, — в scripts/stop-words-allow.txt.
#
# идентификатор карточки трекера: 3–6 заглавных латинских букв, дефис, 1–6 цифр; граница слова — явными классами
(^|[^A-Za-z0-9_])[A-Z]{3,6}-[0-9]{1,6}([^A-Za-z0-9_]|$)
# то же в нижнем регистре (якоря, имена файлов)
(^|[^A-Za-z0-9_])[a-z]{3,6}-[0-9]{1,6}([^A-Za-z0-9_]|$)
# UUID
[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}
# e-mail
[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}
# URL GitHub (в публичном дереве адреса — только плейсхолдерами)
github\.com/
# ссылка на PR чужого репозитория вида владелец/репозиторий#N
[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+#[0-9]+
