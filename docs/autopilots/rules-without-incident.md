Класс `гигиена`. Квартальная ревизия правил без инцидента (README `pm-workflow`, «Правило без инцидента — кандидат на пересмотр»). Триггер — расписание раз в квартал, первого числа (пояс настраивается в самом автопилоте); режим `create_issue`, исполнитель — агент роли PM.

Что сделать: `multica repo checkout <URL этого репозитория>`; `bash scripts/check-rules.sh --list-no-incident` даёт список `файл#якорь · правило`; вставить список в описание карточки таблицей с колонкой «Решение владельца (оставить / пересмотреть / удалить — только если правило не используется / инцидент найден)»; перевести карточку в `blocked` с упоминанием владельца — решение его. По решению: удаление правила (только неиспользуемого и только по согласованию с владельцем) — PR в `pm-workflow` с записью в `CHANGELOG.md`; найденный инцидент — строка в `docs/incidents.md` и ссылка в правиле; пересмотр формулировки — PR без изменения смысла либо с записью в `CHANGELOG.md`.
