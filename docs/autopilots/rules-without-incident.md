The `hygiene` class. A quarterly revision of rules without an incident (the `pm-workflow` README, "Rule without an incident — revision candidate"). Trigger — a schedule once a quarter, on the first day of the month (the time zone is configured in the autopilot itself); mode `create_issue`, executor — an agent of the PM role.

What to do: `multica repo checkout <URL of this repository>`; `bash scripts/check-rules.sh --list-no-incident` gives the list `file#anchor · rule`; paste the list into the card description as a table with the column "Owner decision (keep / revise / remove — only if the rule is not used / an incident found)"; set the card to `blocked` with a mention of the owner — the decision is his. Per the decision: removing a rule (only an unused one and only in agreement with the owner) — a PR to `pm-workflow` with a `CHANGELOG.md` entry; a found incident — a row in `docs/incidents.md` and a link in the rule; revising the wording — a PR without a change in meaning or with a `CHANGELOG.md` entry.
