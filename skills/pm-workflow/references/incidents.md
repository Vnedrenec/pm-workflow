# Резолвер инцидентов

Один адрес на инцидент. Идентификатор — буква (после `Z` — `AA`, `AB`, …), якорь `inc-<буква в нижнем регистре>`. Правило ссылается на инцидент только якорем этой таблицы: из `docs/*.md` — `incidents.md#<якорь>`; из `README.md`/`CHANGELOG.md` — `docs/incidents.md#<якорь>`; из скилла — текстом `docs/incidents.md#<якорь>` (скилл читается вне репозитория). Соответствие буквы карточке трекера, дате и первичной записи хранится в приватном реестре воркспейса, вне этого репозитория; правило ссылается только на букву. Столбцы «Симптом» и «Следствие» — основание правила: из них правило выводится без чтения приватной таблицы. Столбец «Правила» — справочный (держится ревью, не CI).

Прошлые строки не переписываются задним числом: ошибка — новая строка со ссылкой на старую. Новый инцидент — следующая буква здесь и строка в приватном реестре (`README.md`, «Как ссылаться на инцидент»).
